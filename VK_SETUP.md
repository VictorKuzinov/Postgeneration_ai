# Как подключить проект к сообществу ВКонтакте

Пройдите эти 5 шагов — и кнопки «Опубликовать пост» и «Отложить»
заработают. Понадобится примерно 10 минут.

---

## Шаг 1. Убедитесь, что вы администратор сообщества

Публиковать посты может только тот, у кого в сообществе есть права
на управление (вы — основатель или администратор).

Откройте своё сообщество → «Управление» → если вы видите раздел
«Управление», всё в порядке.

---

## Шаг 2. Создайте токен доступа (пароль для программы)

1. Откройте страницу <https://vk.com/dev?act=manageApps>
2. Нажмите «Создать приложение»
3. Тип — «Веб-приложение», название — любое (например «Генератор постов»)
4. Нажмите «Установить приложение» (его увидят только вы)

Дальше — получение токена:

1. В настройках приложения найдите раздел «Токены доступа»
   (или перейдите по ссылке <https://vk.com/dev?act=tokenManager>)
2. Нажмите «Создать токен»
3. Укажите сообщество, в которое будете публиковать
4. Поставьте галочку **«Управление»** (это право публиковать записи
   на стене) и снимите остальные — лишние права не нужны
5. Подтвердите создание (ВК может попросить код из SMS или с почты)
6. Скопируйте полученный токен — длинная строка. Показывается он
   один раз, сразу сохраните его

> Токен — это пароль. Не отправляйте его никому и не публикуйте.
> В нашем проекте он лежит только в файле `.env`, который не попадает
> в git.

---

## Шаг 3. Узнайте номер (ID) своего сообщества

Номер сообщества — это число в его адресе.

1. Откройте своё сообщество
2. Посмотрите адрес в браузере:
   - `vk.com/public123456` → ID = **123456**
   - или `vk.com/club123456` → ID = **123456**

Минус в адресе ставить не нужно — проект добавит его сам.

---

## Шаг 4. Заполните файл .env

Откройте файл `.env` рядом с `app.py` и добавьте две строки
(значения подставьте свои):

```
VK_TOKEN=сюда_вставьте_токен_из_шага_2
VK_GROUP_ID=123456
```

Признаки того, что всё внесено правильно:

- `VK_TOKEN` — длинная строка, начинается с `vk1.`
- `VK_GROUP_ID` — только цифры, без `public`, `club` и минуса
- после правок сервер перезапущен

Итоговый файл должен выглядеть примерно так:

```
API_KEY=sk-or-ваш_ключ_нейросети
MODEL=minimax/minimax-m3.1-flash:free
VK_TOKEN=vk1.a.XXXXXXXXXXXXXXXX
VK_GROUP_ID=123456
```

---

## Шаг 5. Перезапустите проект

Остановите сервер (Ctrl+C в консоли) и запустите заново:

```
python app.py
```

Проверьте: сформируйте пост и нажмите «Опубликовать пост».
Пост должен появиться на стене сообщества.

---

## Как работают кнопки

| Кнопка | Что делает |
|---|---|
| **Опубликовать пост** | Пост сразу появляется на стене сообщества |
| **Отложить** | Пост уходит в раздел «Отложенные записи» ВКонтакте и публикуется сам в выбранное время |
| **В избранное** | Пост сохраняется на компьютере в файл `favorites.json` |

Отложенные посты хранит сам ВКонтакте: после нажатия «Отложить»
откройте сообщество → «Управление» → «Типы записей» → «Отложенные
записи» — увидите свой пост и можете поправить время прямо там.

---

## Если что-то не работает

| Сообщение | Что проверить |
|---|---|
| «ВКонтакте не настроено…» | Заполнены ли `VK_TOKEN` и `VK_GROUP_ID` в `.env`, перезапущен ли сервер. Заглушки (например `123456` или «токен из шага 2») не работают — нужны настоящие значения |
| «Ошибка ВКонтакте: Access token was given to a different origin…» | Токен создан не для этого сообщества — создайте заново в настройках нужного сообщества |
| «Ошибка ВКонтакте: Permission denied» | В галочках токена нет пункта «Управление» — создайте токен заново |
| «Ошибка ВКонтакте: Internal server error» | Проверьте, что `VK_GROUP_ID` — это именно число (123456), без слова `public` или `club` |
| Пост отложен, но не виден | Откройте «Управление» → «Типы записей» → «Отложенные записи» — там лежат все отложенные посты, время можно поправить прямо в ВК |

После любых правок `.env` перезапускайте сервер.

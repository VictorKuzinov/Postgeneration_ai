# Настройки формирования поста

Задают стиль текста, который пишет нейросеть. Меняйте значения после
двоеточия — перезапускать сервер не нужно, настройки читаются заново
при каждом новом посте.

- **Общий тон:** дружелюбный
- **Длина поста:** до 300 символов
- **Количество эмодзи:** 3
- **Стиль заголовка:** обычный

Подсказки:

- «Общий тон» — как нейросеть общается с читателем
  (например: дружелюбный, деловой, экспертный, неформальный).
- «Длина поста» — укажите желаемую длину текстом
  (например: до 300 символов, короткий, примерно 500 знаков).
- «Количество эмодзи» — сколько эмодзи примерно использовать
  (например: 3, 5, совсем без эмодзи).
- «Стиль заголовка» — как оформить первую строку поста
  (например: обычный, с эмодзи, капсом, вопросительный, интригующий).

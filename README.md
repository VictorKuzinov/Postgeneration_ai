# Генератор постов для товара (нейросеть)

Локальный сайт на Flask: вы вставляете ссылку на товар — нейросеть
изучает страницу и пишет оригинальный, живой пост с нужными эмоциями.

## Как это работает

1. Пользователь вставляет ссылку на товар и выбирает настроение поста
2. Сайт отправляет запрос в [OpenRouter](https://openrouter.ai) — единый
   доступ ко множеству моделей (OpenAI, Anthropic, Google и другие)
3. Нейросеть пишет оригинальный пост по ссылке с нужной эмоцией
4. Пост появляется на странице — его можно скопировать одним нажатием

## Настройки

- **Настроения поста** — дружелюбное, деловое, воодушевляющее,
  срочное (акция). Задают «эмоцию» текста.
- **voice.md** — общий тон, длина поста, количество эмодзи,
  стиль заголовка. Правится без кода.
- **Модель** — по умолчанию бесплатная `minimax/minimax-m3.1-flash:free`.
  Другую укажите в `.env`: `MODEL=openai/gpt-4o-mini`
  (каталог: <https://openrouter.ai/models>).
- **Веб-поиск** — `USE_WEB_SEARCH = True` в `app.py` добавляет
  модели суффикс `:online`, чтобы она открывала ссылку в интернете.
  Поиск оплачивается отдельно — на балансе должны быть средства.

## Установка и запуск

```bash
pip install -r requirements.txt
```

Создайте файл `.env` рядом с `app.py` и положите в него свой ключ
OpenRouter (<https://openrouter.ai/keys>):

```
API_KEY=sk-or-ваш_ключ
```

Запуск:

```bash
python app.py
```

Открыть в браузере: <http://127.0.0.1:5000>

> Бесплатная модель (`:free`) не требует средств на балансе, но имеет
> строгие лимиты на количество запросов. Веб-поиск (`USE_WEB_SEARCH`)
> оплачивается отдельно — для него нужен пополненный баланс.

## Структура проекта

```
app.py                  # логика: промпт, запрос к нейросети, страница
templates/index.html    # страница сайта (форма + результат)
static/style.css        # оформление страницы
voice.md                # настройки стиля поста (тон, длина, эмодзи)
.env                    # API-ключ (не попадает в git)
requirements.txt        # зависимости
```

## Где менять генерацию

В `app.py` всё помечено комментариями:

- `MOODS` — какие настроения есть и как они описаны для нейросети
- `build_prompt()` — само задание для нейросети
- `USE_WEB_SEARCH` — открывает ли модель ссылку в интернете
- `MODEL` — используемая модель
- `ask_neural_network()` — запрос к API и обработка ошибок

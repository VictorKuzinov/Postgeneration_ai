# Генератор постов для товара (нейросеть)

Локальный сайт на Flask: вы вставляете ссылку на товар — нейросеть
изучает страницу и пишет оригинальный, живой пост с нужными эмоциями.

## Как это работает

1. Пользователь вставляет ссылку на товар и выбирает настроение поста
2. Сайт отправляет запрос в [OpenRouter](https://openrouter.ai) — единый
   доступ ко множеству моделей (OpenAI, Anthropic, Google и другие)
3. Нейросеть пишет оригинальный пост по ссылке с нужной эмоцией
4. Готовый пост можно скопировать, сохранить в избранное,
   опубликовать в ВКонтакте сразу или отложить на любое время

## Возможности

- **Генерация поста** — по ссылке на товар, с выбором настроения
- **Редактирование** — кнопка «Изменить» открывает текст поста
  в редакторе, изменения сохраняются и используются во всех действиях
- **Избранное** — посты сохраняются в локальный файл `favorites.json`,
  оттуда их можно копировать, публиковать и удалять
- **Публикация в ВК** — кнопка «Опубликовать пост» пишет на стену
  сообщества (нужен токен, см. [VK_SETUP.md](VK_SETUP.md))
- **Отложенные посты** — дата и время в форме; ВК публикует запись
  сам в указанное время (раздел «Отложенные записи» сообщества)

## Настройки

- **Настроения поста** — дружелюбное, деловое, воодушевляющее,
  срочное (акция). Задают «эмоцию» текста.
- **voice.md** — общий тон, длина поста, количество эмодзи,
  стиль заголовка. Правится без кода.
- **Модель** — по умолчанию бесплатная `minimax/minimax-m3.1-flash:free`.
  Другую укажите в `.env`: `MODEL=openai/gpt-4o-mini`
  (каталог: <https://openrouter.ai/models>).
- **Веб-поиск** — `USE_WEB_SEARCH = True` в `app.py` добавляет
  модели суффикс `:online`, чтобы она открывала ссылку в интернете.
  Поиск оплачивается отдельно — на балансе должны быть средства.

## Установка и запуск

```bash
pip install -r requirements.txt
```

Создайте файл `.env` рядом с `app.py`:

```
# Обязательные — генерация постов
API_KEY=sk-or-ваш_ключ          # ключ OpenRouter: https://openrouter.ai/keys
MODEL=minimax/minimax-m3.1-flash:free

# Для публикации в ВКонтакте (как получить — в VK_SETUP.md)
VK_TOKEN=                       # токен сообщества, начинается с vk1.
VK_GROUP_ID=                    # числовой ID сообщества, например 123456

# ProxyAPI — не используется приложением, хранится для справки
PROXYAPI_KEY=
PROXYAPI_URL=
```

> Поле `.env` не попадает в git — секреты остаются только на вашем
> компьютере. Значения-заглушки (например, `123456` или «токен из
> шага 2») не работают — вписывайте только настоящие ключи.

Запуск:

```bash
python app.py
```

Открыть в браузере: <http://127.0.0.1:5000>

> Бесплатная модель (`:free`) не требует средств на балансе, но имеет
> строгие лимиты на количество запросов. Веб-поиск (`USE_WEB_SEARCH`)
> оплачивается отдельно — для него нужен пополненный баланс.

## Структура проекта

```
app.py                  # логика: нейросеть, избранное, публикация в ВК
templates/index.html    # страница сайта (форма, результат, избранное)
static/style.css        # оформление страницы
voice.md                # настройки стиля поста (тон, длина, эмодзи)
VK_SETUP.md             # подробная инструкция: подключение к ВКонтакте
.env                    # ключи (не попадает в git)
favorites.json          # избранные посты (создаётся автоматически)
requirements.txt        # зависимости
```

## Где менять генерацию

В `app.py` всё помечено комментариями:

- `MOODS` — какие настроения есть и как они описаны для нейросети
- `build_prompt()` — само задание для нейросети
- `USE_WEB_SEARCH` — открывает ли модель ссылку в интернете
- `MODEL` — используемая модель
- `ask_neural_network()` — запрос к OpenRouter и обработка ошибок
- `publish_to_vk()` — публикация и отложенные записи в ВКонтакте
- `add_to_favorites()` / `delete_from_favorites()` — избранное

## Частые вопросы

**Почему кнопки одинаковые?** Все действия с постом (копировать,
изменить, в избранное, опубликовать) используют один стиль кнопок —
единый вид на всей странице.

**Пост не публикуется в ВК.** Проверьте `VK_TOKEN` и `VK_GROUP_ID`
в `.env` (инструкция — [VK_SETUP.md](VK_SETUP.md)), перезапустите
сервер. Токен должен начинаться с `vk1.` и иметь право «Управление».

**Нейросеть отвечает 429.** Бесплатные модели ограничены по числу
запросов — подождите минуту и повторите.
